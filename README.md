# Macaroon Service Discovery for Gemini CLI

Connect Gemini CLI to the Macaroon Network public MCP server.

```sh
gemini extensions install https://github.com/kevmoz/macaroon-gemini-extension
gemini extensions list
gemini mcp list
```

Try asking Gemini to compare the Base block number and chain state service contracts. The remote tool set includes payment-bearing execution. Discovery and unsigned quote inspection require no payment.

Website: https://macaroonnetwork.com
Public MCP: https://api.macaroonnetwork.com/mcp
